# Текущее решение по доменной модели

По последующему запросу пользователя модель сокращена до одного доменного класса `Student`. Коллекция связанных объектов, настройка связи, их SQL-запросы и начальные данные удалены из исходников.

Сохраняются `IDomainObject`, общий CRUD-интерфейс `IRepository`, `Context`, реализации `EntityRepository` / `DapperRepository` и переключение в BL. Интерфейсы пользователя не меняются. Существующие данные БД автоматически не удаляются.

Перед коммитом проверяются сборка всех проектов и отсутствие ссылок на удалённый тип. Подробности текущего контракта находятся в `domain-objects.md`.
